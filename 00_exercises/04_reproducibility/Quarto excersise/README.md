# What this is for
This file contains my first try on creating a reproducible manuscript. I took the structure for the files provided in the excersise as inspiration for my own.

# You will find the following files:
Data - contains the penguins dataset
Docs - contains the following four files
1. my-reproducible-quarto-manuscript.qmd - is the quarto R-script
2. my-reproducible-quarto-manuscript.html - contains the rendered quarto script in HTML-format
3. my-reproducible-quarto-manuscript.pdf - contains the rendered quarto script in PDF-format
4. references.bib - contains the BibTeX document for the references used in the quarto document
Results - currently left empty
Scripts - contains two helper scripts
1. dummy.R - is the code to create the flipers and culmen length plot
2. do_addition.R - is the code that contains a written function to do additions. It wil take two nummeric values as input and will provide their addition as output.
